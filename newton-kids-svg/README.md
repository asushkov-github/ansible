# Newton's Laws for Kids — Dynamic SVG

A tiny, kid-friendly interactive website that explains Newton's three laws of motion with playful SVG animations.

## Quick start

Open `index.html` directly in your browser, or run a static server:

```bash
python3 -m http.server 8000 -d /workspace/newton-kids-svg
```

Then visit `http://localhost:8000` in your browser.

## What you'll find

- Law 1 (Inertia): Push a ball and play with friction.
- Law 2 (F = m × a): Two carts show how mass changes acceleration for the same push.
- Law 3 (Action–Reaction): Two skaters push off with equal and opposite forces.

Have fun exploring! 🚀
